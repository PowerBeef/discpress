# The Discpress chdman engine

`engine/mame` holds **chdman from MAME 0.289** (tag `mame0289`, commit `f34f025`) and the parts of MAME it links (including LZMA SDK 23.01's 7z archive decoder and filter C files for browser `.7z` unpacking), 228 files listed in [`FILES`](FILES). It is a fork. Discpress builds it with [`wasm/Makefile`](../wasm/Makefile), for the browser (`build.sh`) and natively (`scripts/build-native.sh`), and nothing else from MAME is needed.

The paths mirror MAME's, so every file can be compared with its original. **[`mame-0.289.diff`](mame-0.289.diff)** lists every change the fork makes across all 34 modified files under `engine/mame/`; Help → About links to it too. This file is the living technical catalog of those changes (as of Discpress 2.0.1); fork workflow, build/rebuild, and licensing rules live in [`AGENTS.md`](AGENTS.md).

## Fork changes (`engine/mame-0.289.diff`)

- **Browser build (`#ifdef __EMSCRIPTEN__`):**
  - helper-worker hooks in `chd_file_compressor` (`chd.cpp`, `chd.h`) and a 48-byte binary progress snapshot (`discpress_progress_t` / `_wasm_progress_ptr`, `chdman.cpp`);
  - `chd_file::wasm_read_ahead` reads a window of stored hunks in one go for `verify`, the extract commands, `copy`, and `-op` parent walks, hands compressed hunks to helper workers, and serves them to `read_hunk` from memory (with the usual CRC check);
  - `verify` and extract use 8 MiB buffers (`TEMP_BUFFER_SIZE`) instead of 32 MiB (or one full hunk when a hunk is larger);
  - compression and `read_ahead` pause while results streamed into a picked folder are waiting to be written (`wasm_out_full`, `chdman.cpp`);
  - Tier-R crash-resumable OPFS checkpoint hooks (`wasm_ckpt_enabled`, `wasm_ckpt_requested`, `wasm_ckpt_save`, `wasm_ckpt_load`; 4-slot SHA-1 state snapshot ring in `hashing.h` and 32-byte/hunk rawmap + SHA-1 deltas in `chd.h`/`chd.cpp`).
- **Resumable commands (`chdman.cpp`):**
  - The compressing commands (`createraw`, `createhd`, `createcd`, `createdvd`, `createld`, `copy`) and `compress_common` are C++20 coroutines (`chdman_task`), as are `verify`, `extractraw`, `extracthd`, `extractdvd` and `extractcd` (which pause while helpers decompress `read_ahead` windows).
  - `main` is split into `chdman_start` (parse the command line) and `chdman_continue`. In the browser, the page starts a command with `chdman_begin` and calls `chdman_resume` when paused (no Asyncify). Natively nothing pauses and `main` runs straight through with upstream's output, messages and exit codes.
- **`unicode.cpp`/`.h`:** unused utf8proc-backed functions are removed.
- **Faster codec trials & encoding with the same output (Tier R):**
  - *Early-abort trial order (`chdcodec.cpp`, `flac.cpp`, `LzmaEnc.c`):* each hunk tries the previous hunk's winning codec first; every other codec receives the best size so far (`set_limit` / `set_give_up`) and aborts once it cannot win (earlier codec slots still win ties, keeping output identical). Generic `flac` keeps its big-endian encoding in its own buffer instead of encoding a third time, and libFLAC skips MD5 when encoding to memory.
  - *Persistent LZMA encoder & epoch hash reuse (`chdcodec.cpp`, `LzFind.c`):* `chd_lzma_compressor` keeps its `m_encoder` alive across hunks instead of reallocating per hunk, activating `LzFind.c`'s epoch-counter hash table reuse (clearing the table only on counter wrap).
  - *Shared CD hunk preparation (`cd_prep_cache` in `chdcodec.h`, `chdcodec.cpp`):* CD codecs (`cdlz`, `cdzl`, `cdzs`) verify ECC, deinterleave sectors, and deflate zlib subcode once per hunk rather than repeating that work for each codec tried.
  - *libFLAC's deterministic math (`window.c`, `lpc.c`, `fixed.c`):* `cosf` and `log` come from [`engine/libm`](libm/README.md) (Arm optimized-routines matching Linux glibc FMA rounding), so browser CD audio matches chdman on Linux byte for byte.
  - *Hashing (`hashing.cpp`):* unrolled big-endian SHA-1 (120 → 650 MB/s in wasm) + SIMD128 helper, and slice-by-8 CRC-16 (300 → 1,450 MB/s in wasm).
  - *ECC (`cdrom.cpp`, `cdrom.h`):* `ecc_verify` and `ecc_generate` compute GF(2⁸) P and Q parity eight vectors at a time in 64-bit words (3.4× faster natively, plus a WASM SIMD128 path; verified against an independent byte-at-a-time implementation on 200,000 sectors and shared with `wasm/ecm.cpp`).
  - *WASM SIMD128 & 64-bit codec paths (identical output across native, WASM SIMD, and WASM scalar):* `3rdparty/flac` (`ENABLE_64_BIT_WORDS=1` 64-bit bitstreams plus SIMD128 paths in `fixed.c` and `lpc.c`), `3rdparty/lzma/C` (`CpuArch.h` `MY_CPU_64BIT` / 64-bit loads, `LzFind.c` SIMD128 `SaturSub` hash rebase + 64-bit `i64` XOR+`ctzll` match loop, `LzmaEnc.c` `LZMA_LOG_BSR`), `3rdparty/zlib` (`crc32.c` `W=8` 64-bit CRC-32, `deflate.c` SIMD128 `slide_hash` + `i64` `longest_match`), and `3rdparty/zstd` (`ZSTD_BIT_64` / 64-bit bitstream and unaligned loads across `bitstream.h`, `fse.h`, `zstd_internal.h`, `zstd_compress_sequences.c`, `zstd_lazy.c`, `huf_decompress.c`, `zstd_decompress_block.c`).
- **C++20 native thread pool & memory layout (`chd.h`, `chd.cpp`, `chdman.cpp`):**
  - `chd_file_compressor` replaces MAME's `osd_work_queue` with a standard C++20 `std::thread`/`std::mutex`/`std::condition_variable` pool (no 16-thread cap, `-np 1` runs inline with zero worker threads, lock-free atomic `hashmap` bucket heads, `compress_abort()` clean teardown, and only 1 `chd_compressor_group` in `__EMSCRIPTEN__`, saving ~30 MiB per job worker).
  - *Dynamic 8 MiB work buffer (`chd.cpp`):* `m_work_buffer_hunks` targets 8 MiB per buffer (clamped to 256..4096 and rounded down to multiples of 256 so stateless Tier-R tail padding stays exact; kept at 256 when walking `-op` parents).
  - *32-byte packed `hashmap::entry_t` (`chd.h`):* splits 64-bit `itemnum` into two `uint32_t` fields so 32-bit WASM packs entries to 32 bytes instead of 40.
  - *Early working-memory release before `compress_v5_map` (`chd.cpp`):* frees dedupe hash maps, work/compressed buffers, codec instances, and checkpoint deltas before `compress_v5_map()` allocates map compression buffers (~80–110+ MiB lower DVD-9 peak RAM).
- **Redump extraction & single-pass Redump verification (`extractcd --redump` & `verify --redump`, `-rd`; `chdman.cpp`):**
  - `extractcd --redump` writes CRLF `.cue` sheets and one `.bin` per track (or `<name>.bin` for single-track discs), reversing `--keepcue` and `--trailer` (below) when present. Without `--redump`, output matches upstream.
  - `verify --redump` computes per-track or ISO Redump sizes and CRC-32s in a single pass during `verify` (with audio swapped back to little-endian and stored pregaps included) without extracting to disk, emitting `Redump: <size> <crc> <name>` lines.
- **Opt-in Tier-C & Tier-X options (`chdman.cpp`, `chd.h`, `chdcodec.cpp`, `flac.cpp`, `cdrom.cpp`):**
  - *Codec plan (`--codecplan`, `-cp` on `createcd`, `createdvd`, `createhd`, `createraw`, `copy`; Tier C):* each hunk tries only the codecs suited to its content — CD audio hunks try `cdfl`, CD data hunks try `cdlz` with an adaptive `cdzl` fallback (reusing `cd_prep_cache`) whenever `cdlz` output exceeds 75% of the hunk, and DVD/raw hunks skip `flac` unless a ~200 ns 64-sample LE/BE stereo PCM probe detects audio. Mixed boundary hunks and non-default codec lists try all slots. The header codec list and both SHA-1s stay identical to 0.289, and selection depends only on hunk content/position so output is identical across thread counts and browser/native builds.
  - *libdeflate (`--libdeflate`, `-ld` on the same five commands; Tier C):* `zlib`, `cdzl`, `cdlz` subcode, and `cdfl` subcode encode with [`engine/libdeflate`](libdeflate/README.md) at level 9 (or level 12 with `--ultra`) instead of zlib level 9 — standard raw deflate decoded by every CHD reader with identical SHA-1s.
  - *Ultra / "Smaller still" (`--ultra`, `-ul` on the same five commands; Tier C):* raises LZMA to level 9 with `fb=273`, `mc=1000` (keeping decoder-visible `dictSize`/`lc`/`lp`/`pb` unchanged), uses libdeflate level 12 when paired with `--libdeflate`, and enables libFLAC exhaustive model + QLP precision search (`-e -p`) with `"tukey(0.5);partial_tukey(2);punchout_tukey(3)"` apodization within max LPC order 12.
  - *Zstandard level (`--zstd-level N`, `-zl 1-22`, default 22; Tier X):* selects the compression level for `zstd`/`cdzs` (used at level 19 by the page's Zstd and MiSTer presets).
  - *Keep cue sheet (`createcd --keepcue`, `-kc`; Tier C):* stores the input `.cue` in non-checksummed `CUES` metadata after the CD track tags so both SHA-1s stay unchanged and `extractcd --redump` restores CATALOG, FLAGS, ISRC, INDEX ≥ 02, and `CDI/2352`. Omitted by the page for Saturn, Sega CD, and PC Engine CD whose strict readers (Kronos, Yabause, jgenesis) reject unknown metadata tags.
  - *Session metadata (`createcd --sessions`, `-ss`; Tier X):* opt-in checksummed `CHSE` multi-session tag (`cdrom.cpp`) for Jaguar CD (required by Virtual Jaguar); never written by default or for strict-metadata consoles.
  - *Lossless repair trailer (`createcd --trailer <file>`, `-tr`):* appends an unlinked `DPRC0001` EOF trailer outside CHD's metadata chain (invisible to all CHD readers, including strict ones, with both SHA-1s unchanged) recording Tier-X layout repairs so `extractcd --redump` restores original files byte for byte.
  - *Strip metadata (`copy --stripmeta`, `-sm`):* strips non-checksummed metadata tags (such as `CUES`) when copying a CHD.
- **Fixes to 0.289's failure handling, security, and descriptor parsers (`chdman.cpp`, `cdrom.cpp`, `cdrom.h`, `chd.cpp`, `chdcodec.cpp`, `flac.cpp`, `huffman.cpp`, `avhuff.cpp`, `bitstream.h`, `osdsync.h`, libFLAC `lpc.c`/`fixed.c`/`stream_encoder.c`, LZMA SDK `LzmaEnc.c`); output for valid 0.289 input is unchanged except `.toc` stored-pregap extraction and GD-ROM round-trip fixes below:**
  - `verify` exits 1 when data disagrees with the header's SHA-1 (unless `--fix` corrects it); outputs never overwrite inputs (`copy -i x -o x -f`, `createcd` overwriting a track file); `extractcd` of a non-CD, `extractdvd` of a CD/GD-ROM, and unit/sector size 0 are errors (exit 1); failed or short reads on `createraw`/`createhd`/`createdvd` and damaged hunks in `extractcd` are errors (exit 1); `dumpmeta` without `-o` prints its banner on stderr; unexpected exceptions exit cleanly instead of crashing.
  - *Cue, EAC, NRG, TOC, ISO, and GD-ROM parser fixes:* fixes MOTOROLA byte-swapping, multi-track shared-file offsets, multi-track WAVE sizing, EAC gaps appended to the previous file (`track_input_entry::pieces`, including `MODE1/2048` → `AUDIO/2352` split pregaps), Nero `.nrg` stored pregaps and sector-size/64-bit `fseeko`/`ftello` checks, full cdrdao `.toc` grammar (`DATAFILE`/`AUDIOFILE`/`FILE`/`ZERO`/`SILENCE`/`PREGAP`/`START`, `#offset` WAVE headers, partial-sector zero padding, stored pregap `.toc` extraction without extra `ZERO`), `parse_iso` sync-pattern + mode typing for 2352-byte multiples, GD-ROM `.cue`/`.gdi`/`--redump` round-trip parity (refusing `.toc` for GD-ROM and guarding mixed-sector-size TOSEC split pregaps), and `cdrom_file` logical LBA pregap reads (`wasm_probe_read` / `cdprobe`). 5,676 real Redump cue sheets match upstream 0.289 byte for byte.
  - *Malformed descriptor & hostile CHD hardening:* rejects 0-track / >99-track / non-sequential / overlapping / out-of-order descriptors, track directives before `TRACK`, missing/empty GDI tracks, malformed WAV headers (64-bit checked reads), and bad NRG chunks; bounds `cdrom.cpp` `sscanf` (`%15s`) and validates `CHCD` alignment; breaks cyclic self-referencing hunk chains (`self_target`, `chd.cpp`) and cyclic metadata chains (Brent cycle detection); validates CHD headers, `size_t`/64-bit map math, hunk block lengths, and `compress_v5_map` Huffman header sizing for tiny CHDs; guards decompressor buffer underflows (`chdcodec.cpp`, `flac.cpp`), `huffman.cpp` lookup/node bounds, `avhuff.cpp` frame bounds, `bitstream.h` shift bounds, and CD subcode output buffer bounds (`chdcodec.cpp`).
  - *FLAC decoder early-EOS & `#16644` handling (`flac.cpp`):* a damaged `flac`/`cdfl` stream that hits `END_OF_STREAM` with 0 samples decoded returns a decompression error instead of looping forever; legacy unpadded final `cdfl` hunks (`#16644`) that decode valid samples before EOS zero-fill the remainder and rely on `read_hunk`'s hunk CRC-16 to verify integrity (corrupt streams fail CRC).
  - *Sanitizer / UB / leak fixes:* unsigned 32-bit math in libFLAC `lpc.c`/`fixed.c` restores (verified on 200,000 random blocks against `-fwrapv`), `memcpy` for unaligned `LzmaEnc_WriteProperties`, `alignof(std::max_align_t)` header alignment in zlib/LZMA allocators, `msf_to_frames` clamp, `LzmaEnc.c` `dist >= kNumFullDistances` guard, libFLAC `stream_encoder.c` null-offset guard, `new[]`/`delete[]` matching, `osd_event::wait` spurious-wakeup guard, and clean option/thread teardown on error unwind. `tests/ui/engine.spec.js` compares these against upstream 0.289.
