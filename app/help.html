How to use

  1. On the Convert tab, choose or drop your disc files. Pick the .cue (or .gdi) together with all of its .bin/track files.
  2. Each game appears as a card. The right chdman command is chosen automatically; open Options to change compression, hunk size or the output name.
  3. Press Create CHD on a card, or Start all at the bottom. Jobs run one after another.
  4. When a job finishes, press Download (on iPhone and iPad the button is called Save to Files and opens the share sheet, which also works inside apps that cannot download). On desktop Chrome/Edge you can Save all to folder.

Add .chd files to extract them back to .cue/.bin, .gdi, .iso or a raw image, to verify their checksums, or to see their details.

A lone .bin without its .cue still works for single-track data discs (a cue is generated), but for discs with music tracks always add the original .cue.

Game identification and renaming

Every disc you add is examined to find its console (PlayStation 1/2/PSP, Saturn, Sega CD, Dreamcast, PC Engine CD, PC-FX, Neo Geo CD, 3DO, CD-i, Amiga CD32/CDTV, NAOMI and more) and its serial number, read from the disc's own boot files and headers.

The game is then looked up in a built-in copy of the Redump database (about 42,000 discs, via libretro-database, /*DBVER*/). When a track's size and CRC-32 checksum match, the dump is an exact, verified copy; otherwise the serial number is used. Results are named after the official title, for example Metal Gear Solid (USA) (Disc 1) (Rev 1).chd. You can turn this off in Settings or type your own name in Options.

For existing .chd files, choose Rename to save a copy with the official name.

Good to know

Privacy

Nothing is uploaded. The real chdman from MAME runs inside your browser as WebAssembly; files are read directly from your device.

Big files

Results are written to the browser's private storage on disk (not to memory), so multi-gigabyte DVD images work if your device has the free space. Download results when they are ready; the storage is cleared when you use Free temporary storage or reopen the page. On desktop Chrome and Edge you can instead have results written straight into a folder of your choice (Settings → Where to keep results).

Speed

Creating a CHD is CPU-heavy. This page spreads compression over several CPU threads (see Settings). Expect a few minutes for a CD on a computer and longer on a phone. Faster to create in Options trades a little size for a lot of speed.

On phones and tablets

The layout adapts to your screen, text size, notch, rotation and keyboard. In a normal browser the whole page scrolls; inside apps that preview files (and when installed on the home screen) the header stays fixed and only the content scrolls. If scrolling ever feels wrong, change it in Settings → Scrolling; Settings → Screen info shows what your device reports.

Keep this page open and in the foreground while it works; the screen is kept awake automatically. If the browser suspends the tab, the job may stop and need to be restarted.

Compatibility of the results

The CHDs are standard CHD v5 files made by chdman from the official MAME 0.289 release, with the same checksums as desktop chdman 0.289 (for data, the very same bytes as the official build), so they work in MAME, RetroArch, DuckStation, PCSX2, PPSSPP, Flycast and other emulators. The Zstandard option needs a recent emulator build.

Everything else

The Advanced tab exposes every chdman command and option: copy, createraw, parent CHDs, hard disk templates, addmeta, delmeta, dumpmeta, listtemplates and more.

About and licenses

Discpress contains chdman from MAME 0.289 (the official release, tag mame0289), compiled to WebAssembly with Emscripten. Two small browser-specific changes were made: a file-system bridge for reading your files and writing results, and multi-threaded compression through helper workers.
